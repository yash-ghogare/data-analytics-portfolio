## 🍫 1. Chocolate Sales Analysis — Power BI

### Overview

An interactive Power BI dashboard created to analyze chocolate sales performance across different countries, products, salespeople, and months.

### Tools Used

- Power BI
- Power Query
- DAX
- Data Visualization

### Analysis

The dashboard focuses on:

- Total Sales
- Total Boxes
- Total Orders
- Average Sales
- Sales by Country
- Sales by Product
- Monthly Sales Trends
- Salesperson Performance

### Key Insights

- Australia has the highest sales among the analyzed countries.
- Smooth Silky Salty is the highest-selling product.
- Ches Bonnell is the highest-performing salesperson.
- Monthly sales fluctuate across the analyzed period.
- Sales performance varies across countries, products, and salespeople.

## 🎬 2. IMDb Movies Analysis — Power BI

### Overview

An interactive Power BI dashboard created using an IMDb movies dataset sourced from Kaggle. The project explores movie ratings, genres, gross collection, certifications, and release-year trends.

### Tools Used

- Power BI
- Power Query
- DAX
- Data Visualization

### Analysis

The dashboard focuses on:

- Total Movies
- Total Profit
- Number of Genres
- IMDb Ratings
- Movie Genres
- Gross Collection
- Top Movies by Gross Collection
- Top Movies by IMDb Rating
- Movie Certifications
- Movies by Release Year

### Key Insights

- The dashboard contains analysis of 999 movies.
- Drama is one of the most represented genres in the dataset.
- The dashboard identifies the top movies based on gross collection.
- The dashboard highlights highly rated movies based on IMDb ratings.
- Movie releases show changing patterns across different years.

## 📈 3. Sales Analysis Dashboard — Excel

### Overview

An interactive Excel sales dashboard created to analyze customer demographics, shopping platforms, product categories, states, order status, and sales trends.

### Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Data Analysis
- Dashboard Development

### Analysis

The dashboard focuses on:

- Male vs Female distribution
- Shopping Apps
- Top 5 States
- Product Categories
- Order Status
- Age & Gender
- Orders by Year
- Orders by Month

### Key Insights

- The dashboard compares customer distribution by gender.
- Shopping platforms are compared based on order share.
- The dashboard identifies the top-performing states.
- Product categories are analyzed to understand category distribution.
- Order status is divided into Cancelled, Delivered, and Pending.
- Customer behavior is analyzed across age groups and gender.
- Yearly and monthly order trends are visualized.
